# Job Application Program - Quick Start Guide

## Overview

3-4 week intensive job application program. Work at library daily, apply to 140+ jobs per week.

---

## Documents

1. **JOB_APPLICATION_INSTRUCTIONS.md** - Read this for complete details
2. **DAILY_CHECKLIST_TEMPLATE.md** - Use every day
3. **WEEKLY_CHECKLIST_TEMPLATE.md** - Track weekly progress
4. **JOB_LINKS_TEMPLATE.md** - Record all job links

---

## Getting Started

### Day 1: Resume
- Update your resume with latest experience
- Create versions for software, teaching, and hardware roles
- Get manager approval

### Day 2 onwards: Applications

**Location:** Library only (no work from home)  
**Hours:** 8 hours + 1 hour lunch break  
**Daily Goal:** 20+ applications

**Weekly Quotas:**
- 100+ Software jobs
- 10+ Teaching jobs (full-time only)
- 30+ Hardware/IT jobs
- Total: 140+ applications

**Platforms (rotate daily):**
- Indeed
- Monster
- Magnet
- Canada Job Bank

---

## Daily Workflow

See DAILY_CHECKLIST_TEMPLATE.md for hour-by-hour details.

**Morning:**
1. Go to library
2. Open daily checklist and job links template
3. Start applying

**Hours 1-5:** Software jobs (14-16 applications)  
**Lunch Break:** 1 hour  
**Hour 6:** Teaching jobs (1-2 applications)  
**Hours 7-8:** Hardware jobs (4-5 applications)

**End of day:**
- Update checklists
- Save all job links
- Plan tomorrow's platform

---

## Weekly Checklist

At end of each week:
- Complete WEEKLY_CHECKLIST_TEMPLATE
- Verify 140+ applications and all quotas met
- Submit to manager

---

## Important Rules

✓ Work at library always  
✓ Apply to full-time permanent positions only  
✓ Track every application link  
✓ Rotate platforms daily  

✗ No work from home  
✗ No part-time or temporary jobs (especially teaching)  

---

## Questions?

Contact manager at end of week or daily if:
- Falling behind on quotas
- Can't find enough jobs - try another platform
- Need clarification
